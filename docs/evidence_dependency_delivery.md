# 证据依赖驱动交付

受保护的比较、计算、条件匹配和选择请求使用一次远程生成，返回本次回答的候选结构。
本地检查引用、输入类型、必需关系、依赖闭包和数值，再映射至既有 `DecisionResult` 和
`StructuredTable`。普通事实问答、本地直答、结构化枚举、展示转换及插件入口保留原有职责。

## 内存合同

- `Fact`：主体 ID、原子属性/值/单位、时间与变体范围、精确来源引用；区分来源陈述、用户条件和假设。
- `Relation`：输入 ID、待证对应关系、引用及假设性质；不是模型签发的证书。
- `Derivation`：两个输入、操作、必要关系及输出口径。代码要求操作对应的关系覆盖两个输入，
  并自动把完整运算前提交给窄语义核验；真实但无关的关系不能代替实际前提。
- `Choice`：全部硬条件匹配，或在显式列出的对象范围内比较最小/最大值。匹配必须覆盖全部用户硬条件；
  偏好不加入硬筛选。排名还需相同单位、项目和可比口径，排名本身不构成推荐资格。
- `delivery`：只接受上述节点 ID。所有事实和派生值从同一执行结果投影；不接受平行自由生成的
  conclusion、reason、table 或 next_actions 作为交付通道。

状态为 `CONFIRMED / UNKNOWN / CONFLICT / HYPOTHETICAL`。未知不能变成否定；失效仅沿实际依赖
传播，不能保留旧派生值或旧选择。假设前提和结果在同一独立列显示，不填进确认值、排名或选择状态。
无效原子候选可以保留精确引用的来源陈述，但不赋予被拒绝的事实归属。

算术仅支持加减乘除、比较及明确覆盖目标的向上取整，不执行任意表达式。使用 `Decimal`，中间
计算保留精度，展示最多两位小数、`ROUND_HALF_UP`。拒绝非有限值、除零、无依据单位换算。
单位只做声明符号的乘除约分，不构建商业计价或完整量纲平台；语义可比性仍需独立核验。

## 语义边界和调用

来源 ID、行号、连续引用片段、重复 ID、悬空/循环依赖、算术和状态传播由代码检查。
引用真实并不证明语义支持，故事实归属、运算关系、条件完整性和比较口径自动枚举为窄核验项。
本地根据引用取回该来源全部已检索 chunk，保留标题、时间与相邻限定，不只发送候选摘录。

默认复用已安装的 `qwen3:4b-instruct-2507-q4_K_M`。每请求最多十批，每批六项，12288 上下文、2048
输出 token、单批 60 秒超时、总调度 180 秒；剩余未完成项保持未知。只连接本机回环 Ollama，
不继承代理、不自动下载权重、不重试、不调用远程审核或远程修复。超长输入不截掉限定后放行。
缺失模型、超时、截断、无效引用或协议失败不能产生确认结果。

本地模型仍可能误判自然语言关系；它不是形式化证明器。有限的负例、正例和跨领域合同不意味着
所有自然语言问题都已解决。判定语义和用户条件覆盖的可靠性需要持续用真实失败样本检验。

## 配置与回滚

`DOCMIND_EVIDENCE_DELIVERY_STRATEGY=dependency` 为默认策略；`legacy_review` 显式保留旧的整答
远程审核策略。切换策略不改变模型配置，旧策略不是新策略失败时的隐含回退。
`DOCMIND_GENERATION_MODEL` 单独选择远程模型，默认 `gemini-3.8-flash`；该模型的受保护生成使用
temperature 1.0、medium thinking、32768 输出上限，普通生成使用 high thinking。
`DOCMIND_RELATION_MODEL` 可显式选择本机已安装模型。改变模型、预算或关键配置后须重新验收，
不继承其他配置的通过结论。新执行链不靠关闭 `DOCMIND_EVIDENCE_SCOPE_BINDING` 减少远程调用。

公开合成合同位于 `public_tests/state/test_evidence_dependency_contract.py`。真实材料、原始返回、
调用账本和验收结果仅保存于 Git 私有范围。旧自由文本测试显式使用 `legacy_review`，新 runner
合同直接覆盖默认策略的一次生成、零远程审核、来源和选择状态。
